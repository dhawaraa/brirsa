# ระบบขอใบรับรองผลงานวิจัย (สถาบันวิจัยพุทธศาสตร์ มจร)
> **Buddhist Research Institute Research Certification System (BRI-RCS)**

ระบบเว็บแอปพลิเคชันสำหรับยื่นขอรับใบรับรองผลงานวิจัยอย่างเป็นทางการของ **สถาบันวิจัยพุทธศาสตร์ มหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย** พัฒนาขึ้นด้วยภาษา PHP (Pure/Native) ร่วมกับฐานข้อมูล MySQL และระบบตู้คอนเทนเนอร์ Docker สำหรับใช้จำลองสภาพแวดล้อมเพื่อความสะดวกในการติดตั้งและทดสอบ

---

## 🛠️ เทคโนโลยีและระบบความปลอดภัย (Technology Stack & Security)
* **Core Backend:** PHP Native / Pure PHP
* **Database:** MySQL 8.0 (รองรับ UTF-8 Unicode เพื่อแสดงผลภาษาไทยสมบูรณ์)
* **Styling (CSS):** Tailwind CSS / Vanilla CSS
* **Containerization:** Docker & Docker Compose
* **Security Hardening:**
  * **CSRF Protection:** ปกป้องการปลอมแปลงคำขอข้ามไซต์ในฟอร์มลงทะเบียนและการอัปเดตระบบ
  * **RBAC (Role-Based Access Control):** ระบบสิทธิ์ผู้ใช้งานในการดูแลจัดการข้อมูลสำหรับฝ่ายแอดมิน
  * **Secure Session:** ควบคุมเซสชันให้มีความปลอดภัยสูง ป้องกัน Session Hijacking
  * **Content Sanitization:** ป้องกันช่องโหว่ SQL Injection และ XSS ในทุกจุดส่งข้อมูล

## ✨ ฟีเจอร์หลักของระบบ (Core Features)
1. **ระบบลงทะเบียนคำขอใหม่ (Request Registration):** กรอกรายละเอียดโครงการวิจัย ข้อมูลนักวิจัย พร้อมแนบเอกสารสำคัญ 8 รายการ
2. **ระบบติดตามสถานะ (Status Tracking):** ค้นหาและดูความคืบหน้าการรับรองผ่านรหัสเฉพาะ (`RSA-XXXXXX`)
3. **ระบบผู้ดูแลระบบ (Admin Dashboard):**
   * กรองค้นหาและจัดแบ่งหมวดหมู่คำขอ
   * ตรวจสอบไฟล์ ดาวน์โหลดเอกสาร และทำการอนุมัติหรือให้แก้ไขข้อมูลเพิ่มเติม
4. **ระบบอีเมลและภาษาแบบทวิภาษา (Bilingual & Mail System):**
   * ตรวจจับการสลับภาษา (ไทย/อังกฤษ) อัตโนมัติทางหน้าเว็บและ URL Parameter (`?lang=`)
   * ตรวจจับความต่างของภาษาในข้อความอีเมล และส่งอีเมลแจ้งเตือนนักวิจัยเป็นภาษาไทยหรืออังกฤษตามภาษาที่เหมาะสมโดยอัตโนมัติ

## 📁 รายการเอกสารประกอบการขอรับรอง (8 เอกสารสำคัญ)
ระบบนี้กำหนดให้นักวิจัยอัปโหลดไฟล์ในรูปแบบ **PDF** ทั้งหมด 8 รายการ ดังนี้:
1. **เล่มเอกสารรายงานวิจัยฉบับสมบูรณ์** (`file_report`)
2. **แบบประเมินตนเอง** (`file_self_assess`)
3. **บันทึกข้อความ สวพ.10** (`file_sp10`)
4. **แบบฟอร์มตรวจ สวพ.10.1** (`file_sp10_1`)
5. **เอกสารรับรองการตีพิมพ์** (`file_cert`)
6. **หลักฐานตรวจอักขราวิสุทธิ์** (`file_plagiarism`)
7. **หลักฐานการมีส่วนร่วมในงานวิจัย** (`file_participation`)
8. **เอกสารรับรองจริยธรรมการวิจัย** (`file_ethics` - *ฟีเจอร์เพิ่มล่าสุด*)

## 🚀 การติดตั้งและเปิดใช้งานในเครื่องส่วนบุคคล (Installation Guide)

### 1. การรันเซิร์ฟเวอร์ด้วย Podman / Docker

#### ก) รันด้วย Podman / Podman Desktop (แนะนำ - เบาเครื่องกว่า):
เปิดแอป **Podman Desktop** หรือสั่งผ่าน Terminal:
```bash
podman-compose up -d
# หรือ
docker-compose up -d
```

#### ข) รันด้วย Docker:
```bash
docker compose up -d
```

หลังจากสตาร์ทระบบเรียบร้อย คุณจะสามารถเข้าใช้งานพอร์ตต่าง ๆ ดังนี้:
* **หน้าเว็บไซต์:** [http://localhost:84](http://localhost:84)
* **หน้าควบคุม MySQL (phpMyAdmin):** [http://localhost:8084](http://localhost:8084) *(ชื่อโฮสต์เชื่อมต่อในระบบ: `brirscer-db`)*

### 2. การอัปเดตโครงสร้างตารางข้อมูลในครั้งแรก
เนื่องจากมีการปรับเพิ่มเอกสารรับรองจริยธรรมการวิจัย (คอลัมน์ `file_ethics`) หลังจากการทำ Docker Setup แล้ว กรุณารันไฟล์ Migration 1 ครั้งเพื่อความสมบูรณ์ของระบบ:
* เปิดเว็บบราวเซอร์ไปที่: [http://localhost:84/migrate_ethics.php](http://localhost:84/migrate_ethics.php)
* ระบบจะทำการสร้างคอลัมน์ `file_ethics` ให้อัตโนมัติ (หากยังไม่มีในตารางฐานข้อมูล)
